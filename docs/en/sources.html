Sources and validation

Last updated: November 16, 2026.

Where the guidance comes from

Sauve's guidance was written from the 2021 recommendations of the European Resuscitation Council (ERC 2021) and from the French first aid reference PSC1.

More recent versions

The European Resuscitation Council has published a 2025 edition of its recommendations. The French PSC reference was revised in 2026.

Comparison in progress

A comparison of the app's guidance with these versions is in progress. Its gaps are listed in documentation/conformite-referentiels.md, in the source code repository.

Validation

The guidance has not yet been validated by a first aid trainer or a doctor. A review by a trainer is planned.

What Sauve is not

Sauve is a memory aid. It does not replace first aid training, or calling the emergency services: 15, 18, 112, and 114 by text message (SMS) for deaf and hard-of-hearing people.

Reporting an error

To report an error in a procedure or a source, write to pilmil.studio@proton.me or open a ticket on GitHub.
